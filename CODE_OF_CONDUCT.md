# Code of Conduct

## Expected behavior

Project participants must communicate professionally, review technical work on its merits, respect privacy, credit other people's work, and avoid harassment or discrimination.

## Unacceptable behavior

Harassment, threats, discriminatory language, deliberate disclosure of private information, plagiarism, and knowingly submitting restricted or malicious material are not accepted.

## Reporting

Report conduct concerns privately to the repository maintainers through an appropriate private GitHub channel. Do not include sensitive personal information in a public issue.

Maintainers may remove content, close contributions, or restrict participation when necessary to protect the project and its participants.
